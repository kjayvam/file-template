# 데이터베이스 마이그레이션

스키마 변경 이력을 SQL 파일로 관리하는 폴더입니다.

## 규칙

- 파일명: `NNNN_설명.up.sql` (적용), `NNNN_설명.down.sql` (되돌리기)
- 번호 순서대로 적용합니다.
- 이미 적용된 파일은 수정하지 않고, 변경은 새 번호의 파일로 추가합니다.
- SQL 문법은 프로젝트에서 선택한 데이터베이스(SQLite, PostgreSQL 등)에 맞춰 작성합니다.

## 도구

마이그레이션 실행 도구(golang-migrate, Flyway, Alembic, Prisma 등)는 아직 정하지 않았습니다.
도구를 정하면 이 문서에 실행 방법을 추가하세요.
