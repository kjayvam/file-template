# web-api

Rust health API를 조회하는 React 기능과 테스트를 제공합니다. 두 앱에 의존하고 App.tsx에 이름 있는 연결 블록만 추가합니다. Docker 내 연결에는 docker-web-api를 추가합니다.

```bash
python3 scripts/template-module.py add web-api --project /path/to/project --with-dependencies --dry-run
```

명령은 카탈로그 루트에서 실행합니다. 신규 생성은 init --name 이름 --project 새경로 --modules web-api을 사용합니다. 소유 파일·의존 관계·검증 계약은 [module.json](module.json), 전체 사용법은 [카탈로그 안내](../README.md)를 참고하세요.
