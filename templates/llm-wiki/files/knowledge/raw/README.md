# 원본 자료

글·논문·직접 작성한 메모를 이 폴더에 넣고 에이전트에게 수집을 요청합니다. 이 안내 파일은 수집 대상이 아닙니다. 필요할 때 `articles/`, `papers/`, `notes/`, `assets/`를 만들 수 있으며 처음부터 분류할 필요는 없습니다.

웹 자료를 저장할 때는 원본 URL·제목·작성자(확인 가능한 경우)·수집일을 함께 남깁니다. 원본의 내용과 개인 메모를 구분하세요. 링크만 저장한 자료는 원문을 읽기 전까지 수집이 끝난 것으로 처리하지 않습니다.

에이전트는 기존 원본을 수정·삭제하지 않습니다. 원본이 바뀌면 사용자가 새 파일로 추가하고 이전 자료와의 관계를 알려 줍니다. 요약·태그·관련 문서 연결은 `wiki/`에 기록합니다.
